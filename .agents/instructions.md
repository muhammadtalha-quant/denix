# Instructions for Agents in Denix

## Project Overview

Denix is a lightweight, aspect-oriented NixOS and Home Manager configuration
built on [Den](https://den.denful.dev) using the Dendritic module pattern.
Reusable aspects encapsulate system and user behavior, and host/user entities
compose those aspects.

- **Primary Machine**: `hp-probook-430g2` (uses `nixos-facter` hardware report
  at `modules/hosts/hp-probook-430g2.json`).
- **Primary User**: `muhammadtalha` (composed in
  `modules/users/muhammadtalha.nix`).
- **Desktop Environment**: Wayland compositor Hyprland with UWSM session
  management and Noctalia desktop shell.
- **Visual Theming**: Managed by Stylix via `extras.theme-catppuccin` supporting
  Catppuccin Macchiato (dark) and Catppuccin Latte (light).
- **Core Editors**: Zed editor (`zed-editor` in Home Manager, `zeditor`
  executable) and `vim` (`EDITOR = "vim"`, `VISUAL = "zeditor"`). Note:
  Neovim, LazyVim, and Zellij are discontinued.

## Flake & Den Architecture

- **Flake Input Management**:
  - `flake.nix` is generated by `flake-file` and is marked `DO-NOT-EDIT`.
  - All flake inputs must be declared or modified in `modules/entry.nix` under
    `flake-file.inputs`.
  - After changing inputs in `modules/entry.nix`, regenerate `flake.nix` by
    running:

    ```bash
    nix run .#write-flake
    ```

  - Flake inputs and dendritic modules are imported automatically via
    `import-tree ./modules`.

- **Namespaces**:
  - Custom namespaces are registered in `modules/namespaces.nix` using
    `inputs.den.namespace "<name>" false`.
  - Configured namespaces:
    - `desktop`: modular desktop aspects (`environment`, `essentials`, `fish`,
      `hyprland`, `kitty`, `noctalia`, `packages`, `services`, `vcs`, `xdg`).
    - `extras`: optional system capabilities such as `theming`
      (`extras.theme-catppuccin`) and `virtualisation` (`extras.virtualisation`).
    - `disko`: declarative storage partitioning (`disko.ext4-simple`).
  - Core aspects outside these namespaces live under `den.aspects.<name>`
    (`nixos-core`, `hyprland-desktop`, host aspects, user aspects).

- **Module Scoping**:
  - Aspects can define `nixos` (system-level) and/or `homeManager` (user-level)
    scopes.
  - Den provides contextual arguments including `host`, `user`, `pkgs`,
    `inputs`, `lib`, and namespace handles (`desktop`, `extras`, `disko`).
  - Maintain clean separation: place system services, hardware drivers, and
    system packages under `nixos`; place user configurations, desktop
    programs, dotfiles, and shell settings under `homeManager`.

- **Global Defaults**:
  - `modules/defaults.nix` establishes base composition:
    - Hostnames and host-defined users are automatically configured via
      `den.batteries.hostname` and `den.batteries.define-user`.
    - Every host automatically includes `den.aspects.nixos-core`.
    - `host.stateVersion` is forwarded to both `system.stateVersion` and
      `home.stateVersion`.
    - Home Manager is configured to use global packages (`useGlobalPkgs =
      true`), install packages to user profile (`useUserPackages = true`), and
      set `backupFileExtension = "backup"`.

## Desktop & Dotfiles Wiring

- **Aggregator Aspect**:
  - `den.aspects.hyprland-desktop` in `modules/desktop.nix` aggregates
    individual modular aspects from the `desktop.*` namespace and applies the
    Catppuccin theme (`extras.theme-catppuccin "dark"`).
- **Subsystems in `modules/desktop/`**:
  - `hyprland.nix`: Configures NixOS `programs.hyprland` (with UWSM and
    XWayland) and Home Manager `wayland.windowManager.hyprland.extraLuaFiles`.
    Lua configs live in `modules/desktop/_dotfiles/hypr/`. Preserve module names
    and require dependencies (`hyprland.keybindings`, `hyprland.hotkeys.*`,
    `lib.keys`, `lib.helpers`).
  - `noctalia.nix`: Pure Nix configuration of Noctalia shell (NixOS service +
    Home Manager settings, bar widgets, panels, and audio visualizer). External
    TOML dotfiles are no longer used.
  - `kitty.nix`: Terminal emulator configuration with fish integration and
    Nautilus terminal launcher.
  - `fish.nix`: Shell abbreviations, functions (`clh`), plugins (`autopair`),
    and `nh` operational aliases.
  - `essentials.nix`: Everyday tools: `ripgrep`, `obsidian`, `zed-editor`,
    `starship`, `fastfetch` (pure Nix schema), `devenv`, `cava`, `btop`,
    `television`, `nix-search-tv`, `localsend`, `gpu-screen-recorder`.
  - `vcs.nix`: Git, Lazygit, Seahorse, and GPG agent setup. Commits and tags
    are signed by default using `user.publicGPGKey`.
  - `services.nix`: System services (Ly display manager, Pipewire, Syncthing,
    Udisks2, UPower, power-profiles-daemon, fprintd, libinput).
  - `xdg.nix`: Portals (Hyprland, GTK), default MIME associations, user
    directories.
  - `environment.nix`: Session environment variables (`EDITOR = "vim"`,
    `VISUAL = "zeditor"`, Wayland/Qt flags).
  - `packages.nix`: Desktop fonts (`newcomputermodern`) and user packages
    (`wl-clipboard`, `google-chrome`, `nautilus`, `claude-code`, etc.).

## Hosts, Users, & Schemas

- **Schemas (`modules/schemas/`)**:
  - `host-schema.nix`: Defines accepted fields on host declarations:
    - `stateVersion`: Compatibility version string (e.g. `"26.05"`).
    - `timeZone`: Timezone string (e.g. `"Asia/Karachi"`).
    - `flakePath`: Absolute path to local flake repository (default
      `"/etc/nixos"`).
    - `withLocalSSH`: Boolean to conditionally enable OpenSSH for local
      network.
    - `withTailscaleSSH`: Boolean to enable OpenSSH, Tailscale daemon, and
      firewall opening.
    - `withFHSCompat`: Boolean to enable `programs.nix-ld` and
      `services.envfs.enable` for running unpatched binaries.
    - `firewallAllowedTCPPorts` / `firewallAllowedUDPPorts`: Lists of integer
      port numbers.
    - `disko`: Submodule with `device` (e.g. `"/dev/sda"`) and `swapSize`
      (e.g. `"4G"`).
  - `user-schema.nix`: Defines accepted fields on user declarations:
    - `hashedPassword`: Password hash string for user (schema default `"0"`).
    - `hashedPasswordRoot`: Password hash string for root (schema default
      `"0"`).
    - `emailAddress`: User email address.
    - `home`: Read-only path (`/home/${user.userName}`).
    - `realName`: User display name.
    - `publicGPGKey`: Public GPG key ID for Git signing.
  - **Rule**: Whenever adding or modifying host or user parameters, always
    update the respective schema first.

- **Host & User Instantiation**:
  - Host declarations: `modules/hosts.nix`.
  - Host-specific aspects & hardware: `modules/hosts/<hostname>.nix` and
    `modules/hosts/<hostname>.json` (Facter report).
  - User definitions: Per-host user data in `modules/hosts.nix`; reusable user
    configuration aspect in `modules/users/<username>.nix`.
  - User aspects compose batteries and aspects directly:
    `den.batteries.primary-user`, `(den.batteries.user-shell "fish")`, and
    `den.aspects.hyprland-desktop`.

## Commands & Development Workflow

- **Development Shell**:
  - Run `devenv shell` to enter the development environment.
  - Tools available: `nixfmt`, `statix`, `markdownlint-cli2`, `marksman`,
    `nil` (Nix LSP).
  - Script available: `zed` (launches `zeditor .`).
- **Formatting & Linting**:
  - Format a file: `nixfmt path/to/file.nix`
  - Check formatting: `nixfmt --check path/to/file.nix`
  - Lint Nix code: `statix check`
  - Markdown linting: `markdownlint-cli2 "**/*.md"`
- **Flake Validation**:
  - `nix flake check` is the standard validation command.
  - To simulate CI locally, replicate `.github/workflows/test.yml` by creating
    `modules/ci-runtime.nix`:

    ```nix
    {
      _module.args.CI = true;
    }
    ```

    Then run `nix flake check`. Remove `modules/ci-runtime.nix` when done.
- **System Operation Commands (`nh`)**:
  - Built-in aliases defined in `modules/desktop/fish.nix`:
    - `nixos-switch`: `nh os switch` (activate configuration immediately)
    - `nixos-boot`: `nh os boot` (set configuration for next boot)
    - `nixos-test`: `nh os test` (test configuration without boot entry)
    - `nixos-update`: `nix flake update --flake $FLAKE_PATH`
    - `nixos-repl`: starts nix repl with `<nixpkgs>` and `lib` pre-loaded
    - `nixos-purge`: cleans old profiles and optimizes store

## Safety Guidelines & Guardrails

- **System Modification Guardrail**:
  - Commands that alter the running or bootable system (`nh os switch`,
    `nh os boot`, `nh os test`, `nixos-rebuild`) MUST NOT be executed unless the
    user explicitly requests building, testing, or switching the system.
- **Storage & Disko Guardrail**:
  - Declarative disk partitioning is specified in
    `modules/disko/ext4-simple.nix`. Never run Disko formatting, partitioning,
    or mounting commands directly. Any disk operations carry risk of permanent
    data loss.
- **Secrets & Privacy**:
  - User and root password hashes and identity data are stored in
    `modules/hosts.nix`. Never echo, log, expose, or commit plain text
    passwords. Never generate unnecessary password hashes.
- **Compatibility Safeguard**:
  - `stateVersion` is compatibility data for NixOS and Home Manager. Never
    change `stateVersion` arbitrarily without a deliberate, verified migration
    plan.
- **Flake Immutability**:
  - Never edit `flake.nix` directly. Always make input adjustments in
    `modules/entry.nix` and regenerate via `nix run .#write-flake`.
